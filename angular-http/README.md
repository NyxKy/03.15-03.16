# angular-http

Progetto Angular del **LAB 03.16 — Chiamate HTTP: da JSONPlaceholder ai fatti sui gatti**
(Modulo 03, Angular). Le istruzioni principali, la struttura e la gestione della chiave
della NASA sono nel [`README.md`](../README.md) alla radice del repository; le risposte alle
domande della traccia sono in [`../RISPOSTE.md`](../RISPOSTE.md).

## Comandi

```bash
npm install
npm start        # ng serve -> http://localhost:4200
npm run build    # ng build (produzione)
```
